# 🍿 Кино Планер

Веб-апликација за планирање излегување во кино со пријатели.

## Што може
- **Избор на филм**: листа со филмови, пребарување, филтер по жанр и додавање свој филм.
- **Планирање**: избор на кино, датум и термин. Апликацијата пресметува:
  - кога треба да тргнете (време за патување + 15 мин резерва),
  - кога завршува филмот (реклами + траење) и кога ќе стигнете дома,
  - вкупни трошоци и колку чини по човек (билети, пуканки, превоз).
- **Мои планови**: зачувани во прелистувачот (localStorage), со копирање/споделување текст за пријателите и бришење.

## Стартување
Не треба инсталација. Потребен е само локален сервер, бидејќи се користат ES модули:

```bash
npm start          # или: python3 -m http.server 8000
```
Потоа отворете http://localhost:8000

## Тестови
```bash
npm test
```

## Структура
- `index.html` — страница
- `src/app.js` — интерфејс и зачувување
- `src/planner.js` — логика (време, трошоци), без DOM
- `src/data.js` — **примерни** филмови и кина (измислени термини и цени — сменете ги со вистински)
- `tests/` — тестови за логиката
